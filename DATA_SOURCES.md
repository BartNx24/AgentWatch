# Dataset credits and preparation

## Online Retail — v0.5.0 onward

Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33.
Source: https://archive.ics.uci.edu/dataset/352/online-retail
License: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/.

The project includes all 66 transaction lines for invoices 536365–536374. Dates and numeric cells are serialized as documented in SOURCE.json; SourceRow identifies the original spreadsheet row. Registers and checklists are derived files, and ReviewStatus is a configured workflow field. Source transaction values, selection details and hashes are retained. These are public source transactions; account permissions, confidential workspace labels, tasks and approval responses are experimental inputs.

## Wine — v0.4.0 and v0.4.1

Aeberhard, S. & Forina, M. (1992). Wine [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5PC7J.
Source: https://archive.ics.uci.edu/dataset/109/wine
License: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/.

The retained source_wine_data.csv is the scikit-learn 1.8.0 distribution copy. It contains 178 observations and 13 measured attributes. The scenario suite groups these values into ten files and adds dataset row references. Its provenance records the exact source-copy hash and the grouping. These older lab requests remain historical experiment cases.

## Initial fixtures — v0.1.0 through v0.3.0

The original fixtures are fictional experiment data created with ChatGPT assistance. Software uses predefined action requests and configured policies; it does not evaluate a live language model. Approval waits are assumptions rather than measured human response times.
